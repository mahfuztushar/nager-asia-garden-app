# Nager ASIA Garden Android App

App name: Nager ASIA Garden
Address: 39 Nilamber Shaha Road, Hazaribagh, Dhaka 1209

Included:
- 32 flats preloaded
- Monthly charge defined by admin each month
- Opening balance entered by admin
- Previous due entered per flat
- Payment entry and history
- Expense entry and history
- Total due and current balance
- WhatsApp reminder
- CSV export for Excel
- Home-page committee: Mr. Litton (সভাপতি) and Mr. Joshim (হিসাবরক্ষক)
- Their photos can be selected from the phone after installation

Build:
Open in Android Studio and Build > Build APK(s)
or push to GitHub and run the included 'Build Android APK' workflow.
